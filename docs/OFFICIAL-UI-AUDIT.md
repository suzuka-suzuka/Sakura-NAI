## 图片编辑器扩图入口修复（2026-10-01）

现在绘图画布越过原图任一边缘时，把当前可见图层合成为保留底图，并自动转为蒙版编辑器，仅选择新增区域。裁剪仍保持绘图模式，空白画布扩展也不会转为没有底图的重绘。撤销／重做一起恢复模式、底图、图层和尺寸；新增扩图不会继承休眠的聚焦重绘开关。保存发送 `infill`，沿用已修复的请求蒙版和原图合成流程。这一入口修复无需新增 relay 协议或费用规则。
